# Construction Rental App

เว็บแอปตัวอย่างสำหรับธุรกิจเช่าวัสดุก่อสร้าง / เครื่องมือ / อุปกรณ์ไซต์งาน

## ฟีเจอร์
- แสดงรายการสินค้าให้เช่า
- ค้นหาสินค้า
- กรองตามหมวดหมู่
- เลือกวันรับของ / วันคืนของ
- คำนวณค่าเช่า + ค่ามัดจำ
- เพิ่มสินค้าลงตะกร้า
- กรอกชื่อลูกค้า / เบอร์โทร
- สร้างออเดอร์ตัวอย่าง
- ดูออเดอร์ล่าสุด

## วิธีรันในเครื่อง

```bash
npm install
npm run dev
```

เปิดเว็บที่:

```txt
http://localhost:3000
```

## วิธีเอาขึ้นเว็บฟรีด้วย Vercel

1. สมัคร GitHub
2. สร้าง repository ใหม่
3. Upload ไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub
4. เข้า Vercel
5. กด Add New Project
6. เลือก GitHub repo นี้
7. กด Deploy

หลัง Deploy จะได้ลิงก์เว็บประมาณ:

```txt
https://your-project-name.vercel.app
```

## สิ่งที่ควรเพิ่มต่อ
- Login admin
- Database จริงด้วย Supabase
- Upload รูปสินค้า
- แนบสลิป
- PromptPay QR
- แจ้งเตือน LINE OA
- ระบบสถานะ: รอยืนยัน / กำลังเช่า / คืนแล้ว / เกินกำหนด
